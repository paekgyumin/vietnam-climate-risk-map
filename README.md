# 🌏 Hanoi Climate Risk Map

하노이 지역의 기후변화 위험을 지역별로 비교하고
사람·동물·식물의 관점에서 분석한 학생 프로젝트입니다.

## 프로젝트 목적

하노이의 지역별 기후위험을 지도에 시각화하여
기후변화가 인간과 생태계에 어떤 영향을 줄 수 있는지
확인하는 것을 목적으로 합니다.

## 주요 위험

- 🌡️ 폭염
- 🌫️ 대기질
- 🌊 침수
- 🌧️ 집중호우
- 💧 가뭄
- 🌳 녹지

## 분석 대상

- 👤 사람
- 🐾 동물
- 🌱 식물

## 주요 기능

### 1. 지역별 위험도

하노이의 12개 지역을 지도에 표시하고
각 지역의 위험도를 1~5단계로 표현합니다.

### 2. 위험도 필터

상단의 버튼을 이용해

- 종합
- 폭염
- 대기질
- 침수
- 집중호우
- 가뭄
- 녹지

중 원하는 위험을 선택할 수 있습니다.

위험도가 높을수록 지도에 표시되는 원의 색이
초록 → 노랑 → 주황 → 빨강 순서로 변합니다.

### 3. 대상별 분석

사람·동물·식물을 선택하면
각 대상에게 관련성이 높은 기후위험을 기준으로
지도에 표시합니다.

### 4. 지역 상세 정보

지도 위의 지역을 클릭하면

- 폭염
- 대기질
- 침수
- 집중호우
- 가뭄
- 녹지

의 위험도를 확인할 수 있습니다.

또한 사람·동물·식물에 대한 영향과
대응 방향도 확인할 수 있습니다.
