# 베트남 기후위험 지도 프로젝트

## 프로젝트명
베트남 기후위험 지도 프로젝트 - Hanoi Climate Risk Map

## 탐구 목적

기후변화로 인해 하노이에서 발생할 수 있는 여러 기후위험을
지역별로 비교하고 지도 형태로 시각화한다.

이번 프로젝트에서는 다음과 같은 위험 요소를 살펴본다.

- 폭염
- 대기질
- 침수
- 집중호우
- 가뭄
- 녹지 환경

또한 각 위험이 사람, 동물, 식물에 미칠 수 있는 영향을
함께 생각하고 대응 방향을 정리하였다.

## 지도 데이터

지도에 표시된 원은 실제 정부가 발표한 공식 위험도 수치가 아니라
학교 탐구 프로젝트를 위해 만든 "분석 지점별 탐구용 추정 지표"이다.

각 지점은 하노이의 도시지역, 하천 및 저지대, 외곽지역,
녹지 및 농업지역 등의 공간적 특성을 고려하여 구성하였다.

따라서 실제 재난 예보나 안전 판단에 사용할 수 있는 자료가 아니다.

## 위험도

1 : 매우 낮음
2 : 낮음
3 : 보통
4 : 높음
5 : 매우 높음

## 기술

- HTML
- CSS
- JavaScript
- Leaflet.js
- OpenStreetMap

## 주요 기능

- 하노이 기후위험 지도
- 위험 유형별 필터
- 사람 / 동물 / 식물 영향 분류
- 지역별 위험도 표시
- 위험도가 높은 지역의 시각적 강조
- 대응 방법 안내

## 프로젝트의 한계

실제 측정된 모든 환경 데이터를 직접 수집한 것이 아니기 때문에
지도에 표시된 위험도는 탐구용 지표이다.

향후에는 기상청, 위성자료, 대기질 측정자료,
침수 이력 등의 실제 데이터를 활용하여 정확도를 높일 수 있다.
